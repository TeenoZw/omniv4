# Omni Industrial Solutions Brand Assets

These assets recreate the supplied logo as web-ready SVGs and separate the brand system from any instructions that may appear inside the reference image.

## Files

- `admin-web/public/brand/omni-logo-full.svg`: full presentation lockup with service discipline icons.
- `admin-web/public/brand/omni-logo-horizontal.svg`: header/sidebar/footer lockup.
- `admin-web/public/brand/omni-mark.svg`: standalone infinity mark for app icons and compact spaces.
- `admin-web/public/favicon.svg`: browser favicon.
- `client-web/static/brand/omni-logo-full.svg`: same full lockup for the customer/marketing app.
- `client-web/static/brand/omni-logo-horizontal.svg`: same horizontal lockup for the customer/marketing app.
- `client-web/static/brand/omni-mark.svg`: same standalone mark for the customer/marketing app.
- `client-web/static/favicon.svg`: browser favicon.

## Palette

- Midnight: `#06162b`
- Ink: `#071a31`
- Steel: `#dfe7ed`
- Electric blue: `#0567f2`
- Deep blue: `#0049dd`
- Surface: `#f6f9fc`

## Usage

- Use `omni-logo-horizontal.svg` for navigation, sidebars, compact footers, and login panels.
- Use `omni-logo-full.svg` for brand pages, proposals, documents, and large empty states.
- Use `omni-mark.svg` for favicons, badges, loading indicators, and very small surfaces.
- Keep at least the height of the lightning bolt as clear space around the mark.
- Prefer the SVGs over the original PNG so the identity remains sharp on high-density screens.
