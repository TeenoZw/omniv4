## Recommended incident types
- Unauthorised access
- Credential compromise
- Device loss
- Data exposure
- Misdelivery / accidental disclosure
- Malware / system compromise
- Configuration error
- Insider misuse

## Evidence to keep per incident
- initial alert or report
- timeline
- affected systems and data categories
- containment evidence
- decision on notifications
- remediation steps
- post-incident review
