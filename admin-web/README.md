# Omni Logistics Admin Dashboard

Administrative dashboard for Omni Logistics onboarding, billing, and support workflows.

## Features

- Device inventory management
- Hub provisioning and subscription setup
- Enquiry intake and quotation follow-up
- Technician workflows
- Audit logs and monitoring
- Responsive design for desktop and tablet

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

Access at: http://localhost:5173

## Build

```bash
npm run build
```

## Project Structure

- `src/` - Source code
  - `components/` - Reusable Svelte components
  - `pages/` - Page components
  - `stores/` - Svelte stores
  - `api/` - API integration
  - `App.svelte` - Root component
- `static/` - Static assets
- `public/` - Public assets
