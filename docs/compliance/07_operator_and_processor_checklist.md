# Operator and Processor Agreement Checklist

Use this checklist for hosting providers, telecom/SIM providers where relevant, support vendors, subcontractors, and any other operator processing personal information on behalf of Omni Logistics.

## Minimum clauses
- operator acts only on documented instructions
- confidentiality obligations
- appropriate security safeguards
- sub-processor approval and flow-down obligations
- incident notification obligations
- assistance with data subject requests where relevant
- return or destruction of personal information at end of services
- audit / evidence cooperation where relevant
- cross-border transfer conditions where applicable
- clear contact points and escalation path
